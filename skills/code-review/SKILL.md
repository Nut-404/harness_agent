# Code Review Skill

Use this skill when the user asks you to review code.

## Process

1. Inspect the relevant diff or file contents before giving findings.
2. Prioritize real bugs, regressions, security issues, and missing tests.
3. Report findings first, ordered by severity.
4. Include the file path and line number for each finding when possible.
5. If there are no findings, say that clearly and mention any residual test risk.

## Output

Use concise Chinese unless the user asks otherwise.
